# Microlink Solutions

Professional website for [microlinksolutions.com.au](https://www.microlinksolutions.com.au) — websites, Shopify, integrations, and products like FuelGO.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build (static export for GitHub Pages)

```bash
npm run build
```

Output is written to `out/`. Deploy the contents of `out/` (plus keep `CNAME` for the custom domain).

FuelGO legal/support pages live under `public/fuelgo/` and are included in the export.
